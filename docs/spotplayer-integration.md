# اتصال SpotPlayer به هوش افزا

## معماری اتصال

1. مدیر در Django Admin برای هر دوره ضبط‌شده مقدار «شناسه دوره در SpotPlayer» (`spotplayer_course_id`) را ثبت می‌کند. این شناسه بسته/دوره در پنل SpotPlayer است، نه شناسه داخلی هوش افزا.
2. کاربر از مسیر عادی سایت خرید می‌کند.
3. فقط پس از تأیید سمت سرور پرداخت و تغییر سفارش به `PAID`، API تلاش می‌کند برای هر آیتم ضبط‌شده‌ای که شناسه SpotPlayer دارد لایسنس بسازد.
4. رکورد لایسنس به آیتم سفارش متصل می‌شود و وضعیت `CREATED` یا `FAILED` را نگه می‌دارد. خطای SpotPlayer نباید پرداخت تأییدشده را به وضعیت ناموفق برگرداند.
5. دانشجو فقط لایسنس‌های سفارش‌های پرداخت‌شدهٔ خودش را از `GET /api/v1/enrollments/spotplayer-licenses` می‌بیند.
6. مدیر می‌تواند صدور ناموفق را از `POST /api/v1/admin/spotplayer-licenses/{order_item_id}/retry` دوباره امتحان کند.

## تنظیمات محیطی

مقادیر را در secret manager محیط اجرا (در این پروژه Infisical) قرار دهید؛ کلید API را هرگز در فرانت‌اند، Git یا لاگ‌ها نگذارید.

- `SPOTPLAYER_API_KEY`: کلید API پنل
- `SPOTPLAYER_BASE_URL`: آدرس پایه‌ای که در مستندات حساب شما اعلام شده است
- `SPOTPLAYER_LICENSE_ENDPOINT`: مسیر ایجاد لایسنس مطابق مستندات حساب
- `SPOTPLAYER_MODE=test`: تا پایان آزمون یکپارچه‌سازی روی حالت آزمایشی بماند
- `SPOTPLAYER_DEVICE_LIMIT=2`: تعداد دستگاه مجاز؛ طبق قرارداد/خرید خود تنظیم کنید

**مهم:** درخواست فعلی از الگوی یک کتابخانه عمومی PHP به‌عنوان مرجع سازگاری استفاده می‌کند (headerهای `$API` و `$LEVEL`، مسیر رایج `/license/edit/` و فیلدهای `_id`، `key` و `url`). این کتابخانه مستندات رسمی SpotPlayer نیست. پیش از Production، آدرس endpoint، شیوه احراز هویت، قالب watermark/device، حالت test و شکل پاسخ را با مستندات جاری پنل ناشر خود تطبیق دهید. پیش‌فرض‌ها تضمین قرارداد رسمی نیستند.

## راه‌اندازی و آزمون

1. از بکاپ دیتابیس مطمئن شوید.
2. پس از استقرار کد، مایگریشن‌ها را اجرا کنید: `python manage.py migrate` (از پوشه backend و در همان محیطی که تنظیمات دیتابیس Production بارگذاری شده‌اند).
3. برای یک دوره ضبط‌شده، شناسه SpotPlayer را در Django Admin ثبت کنید و آن را در حالت آزمایشی نگه دارید.
4. یک خرید آزمایشی را از ابتدا تا انتها انجام دهید و بررسی کنید که پرداخت تأییدشده، ثبت‌نام دانشجو و لایسنس به همان آیتم سفارش وصل شده‌اند.
5. کلید/URL لایسنس نباید در endpoint عمومی فهرست دوره‌ها یا جزئیات دوره نمایش داده شود.
6. پس از تأیید مستندات و آزمون روی حساب واقعی، حالت را مطابق راهنمای رسمی حساب تغییر دهید.

## API همکاری و گالری

- ثبت درخواست همکاری/استخدام: `POST /api/v1/careers/applications`
- فهرست درخواست‌ها (مدیر): `GET /api/v1/careers/applications`
- تغییر وضعیت درخواست (مدیر): `PATCH /api/v1/careers/applications/{id}`
- نمایش تصاویر فعال گالری: `GET /api/v1/gallery`
- ثبت تصویر گالری (مدیر): `POST /api/v1/gallery`

درخواست‌های استخدام فعلاً در Django Admin در بخش «درخواست‌های همکاری/استخدام» قابل مدیریت هستند. برای بارگذاری فایل رزومه، بهتر است در مرحله بعدی upload امن با محدودیت نوع/حجم و storage اختصاصی اضافه شود؛ فعلاً فقط لینک رزومه دریافت می‌شود.
