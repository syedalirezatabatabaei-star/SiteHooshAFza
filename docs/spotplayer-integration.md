# اتصال SpotPlayer برای پخش ویدئو در هوش افزا

## اصل معماری

- دوره‌ها فقط در بک‌اند هوش افزا ساخته و مدیریت می‌شوند: عنوان، توضیحات، قیمت، مدرس، حوزه آموزشی، فصل‌ها و جلسات.
- خرید، پرداخت، ثبت‌نام، وضعیت دسترسی و پیشرفت دانشجو نیز متعلق به سایت است.
- SpotPlayer صرفاً برای نمایش/پخش ویدئو استفاده می‌شود؛ نباید دوره یا قیمت در آن تعریف شود و نباید فرایند خرید یا ثبت‌نام سایت به آن وابسته باشد.
- شناسهٔ ویدئوی هر جلسه در فیلد `Lesson.spotplayer_id` ذخیره می‌شود. این شناسه با شناسهٔ داخلی دوره یا جلسه فرق دارد.

## روش اتصال پخش

1. مدیر دوره را در هوش افزا می‌سازد و فصل‌ها و جلسات را اضافه می‌کند.
2. برای هر جلسهٔ ویدئویی، شناسهٔ همان ویدئو را در فیلد «شناسه ویدئو در SpotPlayer» وارد می‌کند.
3. API دوره، شناسهٔ ویدئو را همراه اطلاعات جلسه برمی‌گرداند. صفحهٔ یادگیری فرانت‌اند باید از Player یا Embed رسمی SpotPlayer برای پخش همان ویدئو استفاده کند.
4. پیش از نمایش ویدئوی غیررایگان، بک‌اند هوش افزا باید دسترسی دانشجو به دوره/جلسه را بررسی کند. شناسهٔ ویدئو به‌تنهایی مجوز دسترسی نیست.
5. شیوهٔ Embed، توکن پخش و هرگونه امضا باید از مستندات رسمی جاری SpotPlayer یا نمونه‌کد حساب ناشر پیروی کند. این مخزن عمداً endpoint یا سازوکار احراز هویت حدس‌زده‌شده‌ای برای پخش تعریف نمی‌کند.

## مواردی که نباید استفاده شوند

- شناسهٔ SpotPlayer در سطح دوره
- ساخت لایسنس هنگام پرداخت
- ذخیرهٔ لایسنس در سفارش
- endpoint مستقل برای صدور یا دریافت لایسنس دانشجو
- وابسته‌کردن تأیید پرداخت به SpotPlayer

## API همکاری و گالری

- ثبت درخواست همکاری/استخدام: `POST /api/v1/careers/applications`
- فهرست درخواست‌ها (مدیر): `GET /api/v1/careers/applications`
- تغییر وضعیت درخواست (مدیر): `PATCH /api/v1/careers/applications/{id}`
- نمایش تصاویر فعال گالری: `GET /api/v1/gallery`
- ثبت تصویر گالری (مدیر): `POST /api/v1/gallery`

مایگریشن `0003_remove_spotplayer_licensing` تغییرات اشتباهِ صدور لایسنس را حذف می‌کند و شناسهٔ ویدئوی هر جلسه را نگه می‌دارد.
